模型与 API Key

已写入 macOS Keychain · 日志中自动 redact

目录白名单

fs / exec 工具的 path 必须 resolve 后落在白名单内，越界直接 ToolError。

~/Desktop
~/Documents
~/Downloads

飞书远程（Cloudflare Tunnel）

启用后把本机 /webhook/lark 映射到公网 HTTPS。客户端必须在运行（托盘也可）。

启用飞书远程

启动 cloudflared，暴露 webhook 回调

https://random-words-1234.trycloudflare.com/webhook/lark

将此 URL 填入飞书开放平台「事件订阅 · 请求地址」。临时 URL 重启会变。
