# MyCowork 页面设计规范

本轮依据用户提供的两张 WorkBuddy 截图重新设计。用户指定的布局与浅蓝色方向优先于原先的 Logo 紫色方案。

- 产品：桌面 AI 办公助手；React 19、Vite、Tailwind、Radix UI、Lucide。
- 技能检索：`AI productivity workspace minimal blue --design-system` 命中 AI-Native UI；采用轻量导航、对话优先、低装饰密度。检索中的营销页结构与紫色配色不适用，按用户截图调整。
- 应用框架：常驻浅蓝侧栏，主内容铺满浅蓝白画布；桌面侧栏初始宽 280px，允许拖拽；窄窗口自动使用 64px 图标栏，不覆盖用户折叠偏好。
- 色彩：侧栏 `#e1f3ff`，选中 `#b6e2fc`，画布 `#f5fbff`，白卡片，主操作 `#007ac5`，正文 `#233e50`，次级文本 `#526c7e`。统一语义变量，深色模式使用独立蓝灰色表面。
- 字体：沿用本地 Inter 与系统中文字体。首页标题 25–36px，页标题 23px，卡片标题 15px，正文与说明 13–16px。
- 新建任务：根据单智能体／多智能体模式显示原有小牛 Logo、居中标题与宽输入框；保留附件、技能、连接器、模型与会话模式操作。
- 助理目录：顶部水平页签、分类筛选和搜索，直接呈现办公助理目录；宽窗口三列卡片，中窗口两列，窄窗口单列。使用真实助理数据与绑定技能，不添加虚构专家。
- 交互：按钮显示悬停、选中、焦点状态；搜索使用 Radix Dialog 管理焦点与 Escape；卡片推荐问题沿用原有任务创建逻辑。
- 图片：沿用原有单智能体与多智能体小牛欢迎图；助理分类使用同一 Lucide 图标家族，避免从参考图复制他人头像、品牌或业务内容。
- 验证：渲染器生产构建、导航与输入回归测试、助理搜索和任务绑定测试、实际 React 组件的隔离预览。

样式入口：`renderer/src/styles/airy-theme.css`；语义色彩：`renderer/src/styles/ds-tokens.css`。

行业插件：打开业务应用时自动隐藏宿主侧栏、任务列表与分栏拖动条，插件占满窗口宽度；顶部保留一条 48px 的返回、应用名称、AI 记录和页面操作栏，为原生窗口按钮留出 88px 空间。窄窗口返回按钮仅显示箭头，保留可访问名称。返回应用列表后恢复原侧栏布局；保留未保存内容确认，进入插件不改变侧栏持久化设置，窗口跨断点缩放不重载插件，宿主搜索快捷键不抢占插件输入。

对比度实测：主操作白字 4.58:1，正文 10.73:1，侧栏次级文字 4.85:1，白卡片说明文字 4.51:1。

根据用户标注精简：首页移除顶部模型入口、任务类型与快捷任务栏；助理页移除精选场景。模型切换放在输入框内的右下工具行。

输入框参照补充截图：桌面宽 800px，空白态高 180px，18px 圆角，一体式白色表面，不画内部描边或底栏分隔；左下 + 收纳附件和工具，右侧模型与圆形向上箭头发送，底栏工作空间与会话模式。输入区聚焦不出现方形蓝框，按钮保留键盘焦点提示。

补充菜单与设置规范：侧栏品牌显示 MyCoWork v{实际应用版本}，底部仅有设置图标。+ 菜单为 200px 白色圆角主菜单，包含添加文件、模式、专家、技能、连接器；搜索目录使用 320px 子菜单、彩色首字母标记与单行说明。小窗口使用 200px 子菜单覆盖父菜单以保证边界可见。设置为居中弹窗，桌面宽 1040px、最大高 720px、12px 圆角，236px 浅蓝分类栏，右侧白色滚动面板与浅灰设置行；窄窗口分类栏横向滚动。弹窗关闭后恢复原入口焦点，保留原页面与聊天草稿。沿用已有设置能力，不添加参考产品的虚构选项。

分栏补充规范：对话、文档预览与运行详情为连续铺满窗口的平面分栏，外层不使用圆角、阴影或卡片间距，顶部工具栏统一高 48px，栏间采用 1px 分隔线。默认对话与预览等宽，保留手动拖拽、宽度记忆和双击恢复等分。侧栏顶部色块宽度由实际 DOM 宽度同步，不使用百分比估算；标题栏仅覆盖侧栏，主内容从窗口顶部开始。文档页随预览栏宽度缩放。预览打开时收起的运行详情不占额外栏宽，使用预览工具栏按钮切换；窄窗口预览占满主区域，详情以可关闭的覆盖面板展示。

首页与目录精简：首页标语使用「把想法变成成果」，发送图标统一为描边向上箭头，不旋转或填充。助理冷启动页保留小牛 Logo，缩小欢迎图与上方留白，三个推荐任务与输入框统一宽度，桌面三列、窄窗口单列，点击仍只填入草稿。自动化页使用独立的单层工具栏，保留任务数、搜索、刷新和新建；项目／空间导航留在项目页，去掉重复计数轮询。自动化标题、工具栏、运行提示与任务列表统一边距，列表元信息允许换行。

标题层级：导航或页签已标明当前页面时，不再显示同名的大标题或单独占行的标题容器。技能直接从管理页签开始，记忆保留说明与功能分组，资料库保留来源分组和选中来源名称，浏览器保留子页签而不重复显示子页名称。移除 Hub 统一外部页标题，工作台与自动化只保留含操作按钮的功能栏。助理目录保留可访问的区域名称与数量，不显示重复的办公助理标题。

技能导航补充：顶部增加独立「skill商店」页签，位于技能与记忆之间。技能页只展示您的技能和内置技能；SkillHub 搜索、分类、评分、目录卡片及安装入口集中在商店，安装状态与本地技能同步，返回管理页刷新已安装列表。商店不添加重复的大标题，页签文字单行展示；窄窗口允许连接器按钮换行，卡片单列且无横向溢出。

导航归并：侧栏将助理与技能、连接器合为「助理 · 技能 · 连接器」，助理仍作为其中的顶部页签。资料库与浏览器移至设置弹窗的分类栏，旧导航事件打开对应设置分类，保留当前页面；浏览器子页签横向排列，窄窗口换行，资料库来源与表单自适应排列。项目页工具栏固定在列表上方，结果区域独立滚动，与工具栏保持 20px 间距，去除旧 49px 吸顶偏移；空间／项目切换、搜索、排序与网格／列表功能保留。

补全问题：聊天记录只显示简短说明与等待状态，表单停靠在底部输入区，每次展示一题。面板沿用输入区宽度、白色表面与 20px 圆角，最大高度为 380px 或窗口高度的 48%，超出部分仅滚动题目内容。标题右侧包含上一题、题号、下一题与收起按钮；选项纵向排列，使用浅蓝编号、细分隔线和选中蓝色行，支持自定义补充。必填题需回答后继续，选填题可跳过，最后统一提交给原任务；返回或收起再展开保留答案。收起后恢复普通输入框，提供「查看问题」入口，提交失败保留答案并支持重试。

已回复的补全问题合为一张「补充信息」记录卡，桌面使用问题／答案两列，窄窗口使用逐行布局；原始提问说明默认折叠，支持复制全部答案。界面不再重复显示同一答案的用户气泡，模型和持久化历史仍保留原始回复；兼容已有会话中缺少关联标记的回答。工作台只在更新确实处于运行和等待阶段时显示进行中的工作，结束或取消后清空任务明细。

工作空间入口归并：移除侧栏的空间名称与下拉菜单，历史任务列表仍按当前空间过滤。首页与已有对话的输入框底栏统一提供空间选择；菜单向上弹出，包含搜索、选中状态、创建空白空间／文件夹空间及重命名。未发送草稿切换空间保留文字、附件和助理绑定，发送使用所选空间的根目录与写入模式；已有对话切换到目标空间的会话，保留原会话的空间归属。重命名使用可键盘操作的弹窗，关闭后恢复入口焦点；窄窗口创建子菜单覆盖父菜单，避免出界。

系统设置归并：界面主题放在系统设置中，位于字体大小上方；移除独立的外观分类。保留浅色、深色与跟随系统的选择和持久化，旧外观入口转到系统设置。

定时任务主题适配：工具栏、表单、授权内容和运行结果使用随主题变化的背景色，选中运行记录使用主题强调底色；避免固定白色背景与深色模式浅色文字冲突。设置弹窗中的工具栏与右侧面板同色，日历图标使用主题品牌色，窄窗口工具栏允许换行。
