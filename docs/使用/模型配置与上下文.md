# 模型配置、思考控制与上下文

## 使用方式

进入“设置 → 模型配置/上下文”。页面分为“连接与模型”和“上下文”两个区域。

“添加连接”或“编辑连接”管理名称、接口地址和密钥。一套连接可添加多个模型，同一家厂商也可建立多套连接。模型编辑只处理模型 ID、显示名称及按需展开的兼容性设置；保存不会改写共享连接。编辑弹窗保护未保存内容。

“设为默认”用于新会话。已有会话保留已选模型；模型被删除时要求重新选择，不悄悄替换。正在运行的任务使用启动时的配置快照。

聊天输入框底部显示“模型名称 · 当前强度”。点开可直接选择模型，并调整其支持的强度或预算，不再提供独立的思考模式开关。只有开关、没有强度或预算的型号采用服务默认；低强度不等于关闭思考，也不能保证固定的费用。不同模型支持的选项不同；无可调选项时不占用界面。切换型号会记住该会话各型号的选择，重新校验是否支持。旧版模型中保存的强度和预算会作为会话初始值保留，旧的开关覆盖不再用于聊天发送或手动压缩；选择“服务默认”明确清空当前会话的参数覆盖，不再回落到旧值。所有更改用于下一次发送，界面显示与提交请求使用同一份选择。

测试连接针对已保存的模型配置发送简短请求，可能消耗 tokens。成功仅证明该请求被服务接受，不证明当前会话选择的思考强度或实际推理质量。

“上下文”区域集中管理每个模型的窗口，以及全局自动压缩阈值。列表显示当前窗口和自动/自定义来源；点击该行“调整”展开设置方式和容量，保存后生效，取消则保留原值。选择“自动”并保存即可恢复自动识别；未知型号暂用 200,000 tokens。手动值不能扩大服务的真实容量。压缩比例默认 80%，范围 10%–95%，实际触发点还会扣除输出预留和必要余量。

聊天框的上下文用量圆环可点击，详情显示当前对话估算、窗口及服务端返回的压缩触发上限；系统提示与工具也会占用上限内的空间。详情中的“压缩对话”采用当前会话选择的模型和思考参数。也可以输入：

```text
/压缩
/压缩 保留关于模型配置的讨论、已作出的决定和未完成事项
```

输入 `/` 显示中文候选，点击、Tab 或部分命令后的 Enter 填入命令；完整命令再按 Enter 执行，Shift+Enter 换行，Esc 关闭候选。当前只有一个候选，上下键保持选中它。中文输入法选字期间不执行命令。命令不作为普通聊天消息发送；带附件时会提示分开发送。

压缩调用模型，消耗 tokens。较早原文分块参与摘要，手动带要求的压缩会重新读取以前已经压缩的原文。原始对话不删除，摘要只改变模型视图。自动整理失败会停止本次任务，保留原文与旧摘要；本次文字和附件可恢复，若已写入新草稿则提供“恢复上次输入”追加恢复，不覆盖新草稿。当前任务运行中禁止手动压缩；失败、取消、会话并发变化、没有缩小或结果仍超过预算，都不替换旧摘要。摘要可能丢失细节，完整原文仍是回查依据。

## 目录与数据流

内置 Models.dev 离线快照，启动不要求访问目录站点。日常设置不显示目录维护入口，也不自动联网更新；内部刷新接口仍保留，仅显式调用时下载 `https://models.dev/api.json`，不上传 Key、私有端点、模型配置或会话内容。校验失败保留旧缓存，缓存损坏退回内置快照。成功后同步后端 registry 并通知界面，运行中的任务快照保持不变。

目录筛选可输出文本、支持工具且具有有效容量的条目，内置版本有 7,161 条。条目数不是已实测兼容模型数量。目录描述模型能力，协议适配负责真实请求，两者独立；不执行远端代码，不新增后台定时更新服务。

## 实现边界

- `electron/models_store.ts` 管理连接和模型。旧的单模型配置逐条迁为独立连接，保留原凭据账户；不按相同 URL 合并。JSON 原子写入；连接先校验，写入失败恢复被替换的 Key。
- `electron/model_runtime.ts` 仅在主进程读取凭据；模型参数经随机内部令牌认证送入后端 registry。前端会话、持久化任务快照不保存明文 Key。
- `llm/model_config.py` 保存不可变配置；TaskManager 在接收桌面、定时或远程任务时解析配置。只重建任务的模型与图，不重建服务器、工具、授权中心和调度器。
- 定时任务恢复使用原配置快照；进程内暂停可保留当时凭据。跨进程恢复需要相同连接身份与 Key 指纹，否则明确拒绝恢复，避免悄悄换供应商。完成/失败后释放内存中的凭据快照。
- 显式 fallback 为每个子模型捕获配置，保留其预算 callback。每次按实际子模型过滤不能跨模型复用的原生思考块，返回结果记录实际来源；工具续轮仍保留工具调用和结果。未登记的环境变量 fallback 只能继承已有窗口估计，建议先登记其独立模型配置以获得准确能力。
- API 参数由 `llm/reasoning.py` 转换。对不支持、相互冲突或超预算的选择明确报错，不静默删除。OpenAI 兼容流式扩展字段通过局部适配保留，原生 Responses/Anthropic 块沿用 SDK 格式。

本次输出上限为 `min(目录输出上限或32768, 32768, 窗口/4)`；思考预算必须小于该上限。输入预算为 `min(目录输入上限或窗口, 窗口-输出上限-1024)`。自动阈值再取输入预算与“窗口×压缩比例”的较小值。思考预算属于相应服务的输出约束，不重复扣除一次。

单智能体、工作组的历史载入和工具循环都使用当前任务预算；发送前还检查系统前缀、工具定义和增长后的上下文。单条输入本身装不下时直接提示，不循环压缩。累计任务 token 成本另行统计，与单次上下文窗口无关。


在已有对话中更换模型，会显示简短提示“对话中更换模型可能降低性能表现”；当前历史超过目标触发上限时，另提示发送前自动整理。提示可关闭，下次发送后消失。选择模型和查询用量不会发起模型请求，实际整理发生在发送时，可能消耗 tokens。

例如 700k 历史从 1m 窗口切到 300k：发送时按新模型预算分块整理较早内容，并保留近期对话；300k 还要为输出、系统提示和工具预留空间。摘要记录生成时的可用输入预算。切到可用输入预算更大的模型后，从完整原文重新组装；装得下就直接使用原文，仍装不下则生成适合新预算的摘要。切换本身不删除已缓存摘要。旧摘要若没有预算记录，只在原文能装下时直接恢复。

空闲时的上下文环显示“当前型号可用的历史视图＋草稿”的估计；运行时优先使用调用的 token 统计。系统指令和工具定义的实际开销在后端发送前计入，空闲估计不是服务端精确计费值。压缩后不再与全部历史估计取最大值。

## 协议覆盖与验证口径

下表表示适配路径；真实型号可选值以其目录记录为准。自动测试用真实 SDK 接入本地模拟 HTTP 传输，并非真实厂商付费请求。

| 连接/预设 | 思考参数路径 | 验证/限制 |
|---|---|---|
| OpenAI | 普通模型 Chat Completions；已识别思考模型 Responses `reasoning.effort` | Responses 实际请求体、默认值与档位校验 |
| Anthropic | `thinking` 控制开关/预算，`output_config.effort` 独立控制强度 | SDK 实际请求体、签名块与跨模型过滤 |
| OpenRouter | `reasoning.effort/enabled/max_tokens` | SDK 流式、工具续轮；不同时设置 effort 与预算 |
| DeepSeek | `thinking.type`、`reasoning_effort` | SDK 流式、工具续轮及 `reasoning_content` 保留 |
| 通义千问 | `enable_thinking`、`thinking_budget`、适用型号的 effort | SDK 请求体、流式与工具续轮 |
| Moonshot | `thinking.type/effort` | SDK 请求体、流式与工具续轮 |
| MiniMax | 适用型号 `thinking.type=adaptive/disabled`、effort | SDK 请求体、流式与工具续轮；只有固定思考的型号不虚构控件 |
| 自定义兼容 | 显式基础模型关联＋协议选择 | 别名不改写；未知地址不靠名字猜协议 |
| Ollama / LM Studio / vLLM | 保留各自列表接口；OpenAI 兼容调用 | 本地服务实际开放的参数需明确配置，不把源模型能力当部署承诺 |
| Google OpenAI 兼容端点 | effort 或 `extra_body.google.thinking_config` 扩展 | SDK 请求体、流式与工具续轮；工具签名扩展保留 |
| Z.ai / 智谱兼容端点 | `thinking.type` | 参数转换路径；未做真实部署验证 |

自动回归还覆盖连接迁移、共享 Key 的失败恢复、目录损坏、双任务交错与配置变化、定时恢复、压缩早期/长消息尾部/已压缩原文、取消与并发冲突、超预算、中文命令和 IME composition 事件。

未验证：各厂商真实计费请求及推理质量、Windows 原生输入法实机选字、真实桌面长任务中切换模型的 PID 观察、完整安装包及 macOS。界面布局和交互已在 Windows 上通过独立无头 Chrome 检查；它不替代这些实机验收。
