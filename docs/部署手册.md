# MyCowork 部署手册

## 1. 下载安装

- **macOS**：打开 CI / Release 产物中的 `MyCowork-*.dmg`，拖入「应用程序」。
- **Windows**：运行 `MyCowork Setup *.exe`（NSIS），可改安装目录。

若 macOS Gatekeeper 提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开；或：

```bash
xattr -dr com.apple.quarantine /Applications/MyCowork.app
```

## 2. 首次启动

1. 启动 MyCowork（首次解压后端可能需 10–30 秒）。
2. 打开 **Agents → 模型**（或 **设置 → API / 模型**）：左侧选 Custom（Anthropic / OpenAI / OpenRouter / DeepSeek…）或 Local（Ollama / LM Studio / vLLM），填写 Key 与模型 ID，点 **测试并保存**（校验通过后才会写入）。
3. 确认标题栏显示后端已连接（`127.0.0.1:端口`）。OpenRouter / 本地 Ollama 等均走 OpenAI 兼容协议，由客户端映射为 `MY_COWORK_PROVIDER=openai_compat`。

任务产物：最终交付物保留在工作区；任务结束时会自动删除 `_scratch/` 与本任务产生的中间过程文件（不会删除工作区外的文件）。

会话预览：优先用 **捆绑的 OfficeCLI watch** 高保真预览 `.pptx` / `.docx` / `.xlsx`；不可用时降级为原有简易预览（docx-preview / HTML / SheetJS）。`.csv` 仍用表格轻量编辑。

## 3. 安全提示

- 写文件 / 执行命令 / 生成文档会弹出 **L1 确认**；请核对路径后再允许。
- 目录白名单默认含用户主目录；可在设置中收紧。
- 飞书远程会把 `/webhook/lark` 暴露到公网：务必配置 `LARK_VERIFY_TOKEN` 与 `LARK_IPS`。

## 4. 验证（M1 烟雾）

在对话中输入：

> 在桌面写 hello.txt，内容 hi

允许确认后，检查桌面是否出现 `hello.txt`。

## 5. 可选：飞书远程

1. 本机安装 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/)。
2. 设置环境变量：`LARK_APP_ID`、`LARK_APP_SECRET`、`LARK_VERIFY_TOKEN`。
3. 设置 → **飞书远程** → 启用，将显示的 URL 填入飞书开放平台「事件订阅」。
4. 配对后的飞书会话会自动批准工具；明确点名需桌面运行的 Skill（如 `weekly_report`）仍会被拒绝。

## 6. 可选：微信远程（ClawBot / iLink）

微信走腾讯 iLink Bot 长轮询，**无需公网 URL / Cloudflare 隧道**。协议对齐本机 AionCore 微信插件。

1. 打开 **设置 → 远程连接 → 微信**，点 **扫码登录**。
2. 用微信扫描二维码，手机确认后客户端会自动启用频道（凭据写入钥匙串：`weixin:bot_token` / `weixin:account_id` / `weixin:base_url`）。
3. 在微信里给 ClawBot 发任意消息；客户端出现配对请求后点 **批准**。
4. 再发一句，办公助手会回复文字；若任务写出了 Word/PPT 等文件，会随后作为微信附件发出（失败则提示本机路径）。HTML 会被剥掉；微信不支持改消息或按钮。

注意：

- ClawBot / iLink 目前仍可能处于灰度，个人号使用需遵守微信用户协议；**建议用小号**，不要用主号做长时间自动化。
- 配对后的微信会话会自动批准工具（生成 Word / 写文件等），无需在电脑上点确认；`rm` 等危险命令仍会被拦截。
- 明确点名需桌面运行的 Skill（如 `weekly_report`）经微信仍会被拒绝；请在桌面客户端运行。
- 状态字面量 `scaned`（缺 n）是腾讯接口的既有拼写，不是 typo。

## 7. 可选：定时 Skill

带 `schedule:` 的 `skills/*/skill.yaml` 会在客户端启动时由 APScheduler 注册（需客户端保持运行）。
