# Citation Verification

Use this reference whenever an output cites laws, articles, cases, standards, regulator rules, or model contracts.

## Verification Checklist

1. Does the cited source exist in user context, retrieved context, or local KB?
2. Is the title exact enough to identify the source?
3. Is the article number, case number, rule number, or standard number correct?
4. Is the source current and effective for the matter date?
5. Does the quoted or summarized text support the claim?
6. Is the jurisdiction China mainland, unless otherwise stated?
7. Is a case used as binding/guiding/reference appropriately?

## Pass/Warn/Fail

- `PASS`: source exists, current/effective, and supports the claim.
- `WARN`: source exists but relation is indirect, source may be outdated, or case has only reference value.
- `FAIL`: source not found, wrong article/case number, outdated source used as current, or source does not support the claim.

## Corrective Action

If any material citation fails:

1. Remove or soften the claim.
2. Replace with verified source.
3. Add uncertainty note.
4. Escalate if the failed claim is central to a high-risk matter.
