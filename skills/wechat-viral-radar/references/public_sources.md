# Public Source Playbook

Use these query patterns when the script cannot collect enough public results.

## Sogou Weixin

- `关键词 10万+ 公众号`
- `关键词 爆文 公众号`
- `关键词 最近 公众号`

Example URL pattern:

`https://weixin.sogou.com/weixin?type=2&query=<encoded query>`

## General Web Search

- `微信公众号 10万+ 爆文 <赛道>`
- `新榜 公众号 爆文 <赛道>`
- `清博 公众号 榜单 <赛道>`
- `西瓜数据 爆款素材库 公众号 <赛道>`
- `微信指数 <热点词>`

## Manual Evidence Checklist

Record:

- title
- account
- date
- link
- visible read-count signal, if any
- why it is hot
- whether it is safe to imitate

## Enhanced Source Placeholders

These are not used by the free public version but can be added later:

- Newrank account dashboards
- Qingbo ranking dashboards
- Xigua Data article/material library
- Yiban browser plugin data
- WeChat Index screenshots or exports
